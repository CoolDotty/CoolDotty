X3C builds web applications, Godot tools, automation systems and self-hosted utilities. The work spans product development, user experience, infrastructure and creative technology.

## Featured work

| Project | What it does | Stack |
| --- | --- | --- |
| [x3c.ca](https://x3c.ca) | Portfolio with live server telemetry, WebSockets and real-time visual experiments. | Astro, React, WebSockets |
| [Shader Stacker](https://github.com/x3cca/Shader-Stacker) | Sprite-stacking toolkit for 2.5D graphics in Godot 4. | Godot, GDScript |
| [Friends vs Friends Deck Builder](https://friendsvsfriends.help/) | Browser-based deck builder for the card-driven arena shooter. | React, JavaScript |
| [n8n QuickBooks Web Connector](https://github.com/x3cca/n8n-QuickBooks-Web-Connect) | Connects QuickBooks Desktop workflows to n8n through QBWC. | TypeScript, n8n |
| [n8n XLSX to PDF](https://github.com/x3cca/n8n-xlsx-to-pdf) | Converts spreadsheet attachments to PDFs through headless LibreOffice. | TypeScript, LibreOffice |
| [GameSewer.com](https://gamesewer.com) | Website for a Vancouver indie-game showcase and community. | Astro |

## Technical focus

- TypeScript, JavaScript, React, Astro and Next.js
- Godot Engine, GDScript and game-development tools
- n8n integrations, document automation and business workflows
- PostgreSQL, Supabase, WebSockets and self-hosted infrastructure
- Product interfaces, design systems and accessibility
